## Install on Windows

Windows 10 (version 1809 or later) or Windows 11, 64-bit.

1. Install [VB-CABLE](https://vb-audio.com/Cable/) (free). Voxwright plays
   your changed voice into it, and chat apps record from it. Its setup needs
   administrator rights; VB-Audio recommends restarting Windows afterwards.
2. Download `Voxwright-...-windows-x64-setup.exe` below and run it. It
   installs for your account only and needs no administrator rights. The
   installer is not code-signed yet, so Windows SmartScreen warns: choose
   **More info**, then **Run anyway**.
3. Start Voxwright. The setup guide picks your microphone and checks the
   virtual cable.
4. In Discord, Zoom, Teams, OBS, or your game, choose
   **CABLE Output (VB-Audio Virtual Cable)** as the microphone, and keep your
   headphones as the output.

Installing VB-CABLE can make it the Windows default speaker and microphone.
If you stop hearing other apps, set both back to your own devices in
Settings, System, Sound.

macOS: no download yet; see "Building from source" in the README.
